Task board

What to work on next. Claiming a task opens a pre-filled GitHub issue so nobody duplicates your work. The board is rendered from tasks.json, so update it in your PR when you ship.

    Contribute

    1. Pick an open task above. Good first issues are a gentle start.
    2. Click Claim on GitHub to open an issue, so others know it's taken.
    3. Fork, branch as feat/<task-id>-short-name, and open a PR with tests.
    4. Mark the task done in tasks.json in the same PR.
    5. Say hello in the AIPath channel on Discord.

    Contributing is free and open to everyone, and this track is aimed at people with 2–3 years of AI/ML experience. It gives you experience and portfolio work, but not a certificate or reference letter. Those come with the paid internship plans.

    Run it locally

    git clone https://github.com/SJA-Pathway/AIPath.git
cd AIPath
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest                          # run the tests
uvicorn aipath.api:app --reload # API at :8000/docs
